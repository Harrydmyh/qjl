## 实战：把「不容错过的双十一活动」合集补到 200 条（合集 id 2098411，群 PspU4o9_bsxkBH0_6c6cef00）

代码：`fetch_feed_7d.py`（并发分页抓群主页近 7 天团，缓存 /tmp/feed_7d.json）+ `collection_fill.py`（筛选+去重+写回，默认 dry-run，`--apply` 才写）。
清单：`合集补充清单_20261105.csv`（189 条）；原状备份 `data/collection_2098411_before_20261105.json`。

口径（默认实现）：开团时间在近 7 天内的在售团 → 这批团的 orderCount 必然全产生在 7 天内 → 再筛 ≥20 单。
实抓 1697 个近 7 天团，692 个 ≥20 单，同款合并后 661，取 200（双十一优先占位 + 按销量补足，展示按销量降序）。

**关键坑 / 结论：**
- `act_collection_create` **即使 body 带 actCollectionId 也是新建一条**（实测拿到新 id 2098596）。原地改必须用 **`act_collection_modify`**（保住 id/createTime/已分享链接）。
- `act_collection_modify` 的 `actIdList: []` **被忽略**（不会清空）；也没找到删除接口（`act_collection_delete` 等全 404），误建的只能用改标题标记，删除要去 App 里点。
- 合集上限实测支持 200 条（该号历史合集多条正好 200）。
- `query_ghome_feed_back_v2` 是**无限流**（该群 32 万活动），必须按 createTime 边界停：它是「置顶 + 时间倒序」。
- `feedGroupSalerRootActDTO.orderCount` 才是群内订单数；`saleAmount` 不可当 GMV 用（数量级对不上）。
- **没有**「近 7 天有单」的 per-act 接口：`get_last_order_by_act_id?actId=`（注意 actId 是 **query 参数**，放 body 会报 "Required Long parameter 'actId' is not present"）只返回 lastOrderNo=累计第 N 单，无时间。
- mina token 拿不到 PC 侧订单接口：`/order/customer/manage/find_orders`、`/activity-accessory/pc/order_activity_list/order_manage` → 404 / 「权限不足」。
- 可用但没用的：`/ghdata-biz/api/ghData/queryGhGoodsRank`（dataType 只能 10/20/30/40/50，只返回 top30 商品，非全量）。
- 同款判据要防「换购小件」：玛博牧业每个团都挂「99秒杀福利京都板前特调鲜甜烧肉汁」，只按名字相同会把和牛/肋条并成一条 → 必须用 core._names_same 的 50% 占比阈值。
- 找接口的通用技巧：抓网页版 `main.86b9369b3b3d2d73b283.js`（5.7MB）里有全量 API 路径，gateway 对不存在的路径返回 404、参数错返回带字段名的 400，可用来枚举。

## 品类判定：彻底删掉关键词表，只让模型判（23:30）
- core.py 里 `_FOOD_KW/_HEALTH_KW/_NOT_FOOD_KW` 三张词表全部删除（-5446 字符）；`_classify_kind` 只剩「低值」= 全规格最高价 ≤10（价格是算术，不算正则）。isFood/isHealth 一律先 False，等模型填；**模型挂了就这批不筛**，日志里 `llm_kind_ok=false` 会提示。
- 省 token 的四招（实测 **22 token/商品名**，885 个名字 ≈ 8 次请求 / 19.4k token）：
  1. 批大小 120（+2400 字符上限），系统提示只付一次
  2. 输出只要 `{"c":[0,1,2,3,...]}`，比 `{"i":0,"food":true,...}` 省 4~5 倍
  3. 缓存 key 用归一化名字（去 emoji/标点/大小写），换前后缀也能命中
  4. **编号必须从 1 开始**：0 起编号模型会少给一位（实测 39 vs 40、119 vs 120，全批判失败 → 回滚成 0），1 起就稳定
- 提示词要点（v4）：能入口吃=1；口服保健=2；**外用一律 0**（面膜水乳面霜精华、眼贴/暖贴/膏药、滴眼液、泡脚包、洗护，「丹/膏/精」字号的化妆品也是 0）；厨具/服饰/食品级包装/鲜花绿植 0；拿不准 0。
- 缓存 `data/kind_cache.json` v4；改提示词必须 +1 版本号，否则旧判定一直命中。
- 结果（875 条）：食品 196、保健 14、低值 9。
