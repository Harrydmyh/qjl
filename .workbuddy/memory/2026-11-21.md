## 日间集市加三层去重（19:40，用户要求）
- 用户口径：一样的产品只留一条 —— ①底层商品库同源 ②链接内部标题 90% 以上文字一样 ③内部图片重合 5 张以上。
- 实现 `Deduper` 类（daily_collection.py）：按优先级从高到低过一遍，撞上已入选的就丢，**留下优先级更高的那条**；倒排索引（goodsId / spuId / 图片键）避免 O(n²)。
  - 同源判据：商品的 `goodsId` 或 `spuId` 有交集（`general_goods` 返回里带 spuId）。
  - 标题判据：归一化（去 emoji/标点、小写）后 `SequenceMatcher` ≥ 0.90；短串是长串子串算 100%；长度差 >45% 直接不比；长度 <6 的标题不参与（防「赠品」互相误杀）。活动名和商品名都参与。
  - 图片判据：`goodsPicList` 全量 + 活动 `picList`，路径去 query 去尺寸后缀后取「目录/文件名」两段，交集 ≥5 张。
- **踩坑**：`pick()` 末尾又执行 `order = sorted(picked, ...)`，把去重剔除的条目全捞回来了（首轮独立校验发现 Relu 内裤两条仍在），改成只排去重后的这一份。
- 缓存结构升级 `CACHE_VER=2`（旧缓存没有 spuId 和全部图片，去重会退化）：首次跑重拉 2953 个团约 40 秒。
- dry-run 改为只写 `data/coll_preview.json`，**不动 `coll_selected.json`**；同日拦截只在 `--apply` 时生效，dry-run 随时可看。
