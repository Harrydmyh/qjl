### 做了什么
1. **访问密钥闸门**（`server.py` 的 `access_gate` 中间件 + `is_local_request`）
   - `config.json` 里设了 `access_key` 才启用；没设 = 完全不生效（默认状态不变）。
   - **本机直连免密钥**（对端 127.0.0.1/::1 且**没有** `x-forwarded-for` / `x-forwarded-host` /

   - **刻意不用 HTTP Basic**：嵌入式预览面板里浏览器原生弹窗会被静默吞掉（老坑）。
   - 新接口：`GET /api/access`（只看是否启用）、`POST /api/access/rotate`（生成/轮换）、
     `POST /api/access/disable`。`GET /api/config` 已把 access_key 一起过滤掉（只返回 token 前 20 字符 preview）。
   - 前端：拦一层 `fetch`，遇 401 就在页顶插一条红条提示「加 ?k=」。
2. **launchd 常驻**
   - `~/Library/LaunchAgents/com.qjl.opener.plist`（RunAtLoad + KeepAlive + ThrottleInterval 10，
     日志 `/tmp/qjl_server.log`，显式设 NO_PROXY）。
   - `start-daemon.command`（双击启用常驻）/ `stop.command`（双击停止）。
   - `stop.sh` 已改：**先 `launchctl bootout` 再杀端口** —— 不卸任务的话 KeepAlive 会立刻把它拉回来，
     看起来像「停不掉」。
   - ⚠️ **`launchctl bootstrap` 我这边注册不了**：`gui/<uid>` 和 `user/<uid>` 都报
     `Bootstrap failed: 5: Input/output error`（关沙箱也一样，plist `plutil -lint` 是 OK 的）。
     注册 launchd 任务必须在用户自己的交互会话里做 → **让用户双击 `start-daemon.command`**。

## 用户澄清了真正的目标：前端挂 Vercel、后端在这台 Mac
> 「电脑开着当服务器，前端页面挂到 vercel 啊这种上，点击开团以后请求发到我这台电脑上开始跑，

### 架构（已按此改造）
浏览器 → Vercel 静态页 → HTTPS + `X-Access-Key` → Tailscale 私有隧道 → Mac `127.0.0.1:8765` → 群接龙接口。
「关掉页面也继续跑」本来就有：开团任务是服务端 `_job_thread`，与浏览器无关。

### 改了哪些（这一轮）
1. **后端开 CORS**（`server.py` 末尾 `app.add_middleware(CORSMiddleware, …)`）
   - ⚠️ **必须放在最后 add**：Starlette 的 `user_middleware` 是 `insert(0)`，最后加的会变成**最外层**；
     CORS 在最外层才能给「闸门返回的 401」也补上 CORS 头，否则前端只看到不可读的跨域错误。
   - 预检 OPTIONS 由最外层 CORS 直接应答，不会走到密钥闸门（闸门里也额外放行 OPTIONS 兜底）。
   - 默认 `allow_origins=["*"]`（跨域用请求头带密钥，不依赖 Cookie）；可用 `cors_origins` 收紧。
2. **收紧「本机免密钥」判据** `is_local_request`：原来只看「对端是回环 + 无代理头」，
   测试发现**跨站 Origin 也会被误判成本机**。现在要四个条件全满足：
   ① 对端回环 ② 无代理头 ③ Host 是回环主机名 ④ 没有跨站 Origin。
3. **新增严格模式** `strict_access_key`（`config.json`）：开了之后连本机也要密钥。
   `POST /api/access/strict {strict:true}`；`GET /api/access` 会返回 `strict`。
   挂隧道时必开 —— 反代（Go httputil）可能把 Host 改写回 127.0.0.1，穿透上面 ③ 的白名单。
4. **前端支持跨域**（`index.html`）：
   - `API_BASE` 解析优先级 `?api=` > `localStorage` > `window.__QJL_API__` > 同源；
   - `ACCESS_KEY` 解析 `?k=` > `localStorage`；
   - 新增 `apiUrl()` / `apiFetch()`，把**全部 11 处** `fetch('/api/…')` 换成 `apiFetch('/api/…')`
     （一次 `replace_all` 搞定），自动补后端绝对地址 + `X-Access-Key` 头。
   - 跨域**不能用 Cookie**（第三方 Cookie 会被浏览器拦），所以统一走请求头。
5. **前端发布目录** `deploy/`（`index.html` + `vercel.json` + `README.txt`），
   不含后端代码/数据/密钥。改完前端记得 `cp index.html deploy/index.html`。
6. `开启远程访问.command` 升级：改用 **`tailscale serve --bg --https=443 http://127.0.0.1:8765`**
   （必须是 HTTPS：Vercel 页面是 https，混内容会被拦），并自动打开严格模式。
   想让没装 Tailscale 的设备也能用：`tailscale funnel --bg --https=443 http://127.0.0.1:8765`。
