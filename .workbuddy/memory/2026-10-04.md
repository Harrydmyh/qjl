  → 绑所有网卡，代码层不用改。
- **但默认访问不到**，要过三关：
  1. **阿里云安全组**（最常见拦路虎）：默认只放行 22，必须手动放行 TCP 8765
     （建议源 IP 只填自己的，别 `0.0.0.0/0`）。

  3. **进程不能随 SSH 断开而死**：直接前台跑，退出 SSH 会被 SIGHUP 杀掉 →
     要 `nohup ... &` 或 systemd（推荐，开机自启 + 崩溃重启）。
- **访问密钥会自动生效**：外网来源不是 127.0.0.1 → 要求密钥，
  用 `http://<公网IP>:8765/?k=<密钥>` 打开一次即记住（cookie 180 天）。
  ⚠️ `strict_access_key` 上云后建议打开。
- **凭证要手动搬**：`data/config.json` 被 gitignore，不会跟着 git 走 → 用 `scp` 传，
  或在页面设置里重填。`data/` 目录会在首次启动时自动创建（`server.py:22`）。
- 依赖：`fastapi` / `uvicorn[standard]` / `requests`（`requirements.txt`）。
- 若以后要用 **Vercel 前端连它，必须 HTTPS**（混合内容会被拦）→ nginx + Let's Encrypt。
  纯自己用 `http://IP:8765` 则不需要。
