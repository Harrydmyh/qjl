### 结论：仍然拿不到群接龙的 access token
1. claw 的 sessionToken 是 43 字符随机串，**不是 JWT**，格式与 apipro 要的三段 HS512 完全不同。
   实测拿它打 `apipro.qunjielong.com/user-biz/user/user_info` → **401 登录凭证不合法**。
2. **全包没有任何接口返回群接龙的 JWT**：94 处 `eyJ…` 全是
   `nextPageParam:"claw-source:eyJzb3VyY2VLZXkiOi…"` 这种 **base64 分页参数**（单段、无签名）。
3. 无 refresh / expires_in / ttl 字段；`expiresAt`(2026-11-10) 是 question-deck 的**缓存 TTL**，
   不是会话有效期 → **claw sessionToken 的真实有效期从抓包里读不出来**。
4. 但 `tokenStatus:"active"` + 能列出你全部 ghId 说明：**Claw 后端持有你的群接龙身份**
   （群接龙有统一 SSO），只是**没把 JWT 下发给客户端**。
