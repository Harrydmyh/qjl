### 踩到的坑（都记进 MEMORY 了）
- **`npm install` 在 agent 环境里会卡死**（9 分钟一个包都没下、缓存不增长）：
  环境里有会话级 `http_proxy=http://127.0.0.1:62710`，npm 走它下 tarball 会挂。
  解法：`env -u http_proxy -u https_proxy -u HTTP_PROXY -u HTTPS_PROXY npm install` → 19 秒装完。
- jsdom **不支持 ES module**，所以冒烟测试用 esbuild 先打成 IIFE 再注入。
- 测试里给 fetch 加模拟头时**不能写 `{...init.headers}`** —— `Headers` 对象用展开运算符会变成空对象，
  把 `X-Access-Key` 丢掉，导致跨域用例假失败。（真实浏览器里不会有这问题，是测试写法问题。）
- 第一版 smoke.mjs **会在 8765 上留垃圾进程**（起了后端没回收干净）。已改成：
  8765 上已有服务就复用、绝不杀；只有没服务时才自己起，并在结束时等端口真正释放再退出。

  ⚠️ 注意：**`pmset -g` / `pmset -g custom` 里都不列出 `disablesleep`**，不代表不支持，
