# 2026-11-07

## 汤团² 开团面板：关键字筛选 + 增量勾选（22:40）
用户两个需求：① 按关键字（如「棉服 羽绒服」）筛出来专门开这几个；② 第一遍选好的清单，第二遍筛完能追加（增量），且要能选「保留 / 全部重来」。

- 关键字：`splitKeywords()` 按空格/逗号/顿号/分号/竖线拆词，`matchKeywords()` **任一命中即保留（OR）**。
  搜的是同义词（棉服/羽绒服、马甲/背心），用 AND 会一条都搜不到。匹配范围 = 活动名 + 商品名 + 主商品名 + 供应商名。
  开团面板（`openSearchInput`）和活动列表（`searchInput`）都换成了这套，占位符改成「关键字，空格分隔（棉服 羽绒服）」。
- 增量勾选：新增 `openKeepSel`（默认 **false** = 旧行为：换筛选按当前结果重勾，搜完就是待开的那批）、
  `openAutoFilled`（只在第一次预勾一次）、`openVisibleIds`（算「已选里有多少在本屏」）。
  勾上「保留已选」= 换词不清空，再点「全选本屏」即追加；「重来」= 清空 + 按当前筛选重勾。
  空结果时**不再清空**已选（`if (!openKeepSel) openIds.clear()`）。
- 统计行加了「（本屏 N 个）」，全选按钮文案改「全选本屏 (N)」，避免误以为清掉了别的屏。
- 实测（11-05 那批 875 条）：「棉服」17 条、「羽绒服」20 条、「棉服 羽绒服」36 条（其中可开且非食品 21 条）。
- 新增「确定并开团 (N)」按钮（开团面板工具栏右侧）：筛完直接点，不用滚到右下角。它读的是**此刻的 openIds**，先 `openAutoFilled=true` 再 `startOpen()`。
  ⚠️ 里面**不能**再调 `renderOpenTab()`：`openKeepSel=false` 时 render 会按当前屏重勾，把用户手动取消的那几条勾回来。
- 面板直达：`index.html` 末尾加了 `?panel=open|activities|history` → 按 `nav-<name>` / `panel-<name>` 存在才 `switchPanel`。
  所以「打开汤团²开团页」= 预览 `http://127.0.0.1:8765/?panel=open`（服务在跑时，改前端不用重启）。
- 取消自动刷新（用户要求：只有点按钮才刷新）。所有会打 `/api/fetch` 的隐式触发全部改成「标脏」：
  天数、拉取方式（最近/每周/日历）、星期+次数、日历选日/清空/快捷选 7 天、含已跟过、供应类型、复团预设。
  `markFetchDirty(原因)` → 刷新按钮转黄（`.btn.btn-dirty`）+ 按钮右侧 `.dirty-hint` 写「改了啥 · 点刷新列表生效」；
  `resetFetchBtn()` 拉取结束恢复，`clearFetchDirty()` 在 done 事件里清（带 `fetchDirtyAtStart` 快照，拉取途中又改的不清）。
  仅剩显式入口：刷新按钮、日历「拉取所选」、「用 X 定向拉取」、定向供应商输入框回车、`applyRangeMode(doFetch=true)`（现无调用方）。
  本地视图筛选（品类/供应商/可开团/关键字/排序）仍即时重渲染 —— 不打网络、不清勾选。
- 顺手修：刷新按钮一点就丢图标 → `FETCH_ICON` 常量 + `innerHTML` 重设；窄屏 `.dirty-hint` 限宽 116px 换行。
